# Дом за лето
Сайт о строительстве и переезде в Крым. Первая версия: проекты, выбор фасада, интерьерной палитры и сада, сохранение комплектации, квиз и маршрут переезда.

## Запуск
Откройте index.html в браузере или запустите `python3 -m http.server 8080` в каталоге сайта.

## Границы версии
Подбор сохраняется в localStorage. Кнопка скачивания выдаёт текстовый бриф; печать позволяет сохранить его в PDF. Данные не отправляются на сервер. Изображения отделки — концепции, а не автоматический рендер выбранного дома. Три интерьерные палитры используют общую иллюстрацию с явной подписью. Цены, наличие товаров, договорная комплектация и сроки уточняются индивидуально. Контакт для звонка: +7 978 724-54-24, предоставлен владельцем сайта.

## Развитие
Подключение подтверждённых контактов, серверного приёма заявок, Битрикс, каталога поставщиков с актуальными SKU, калькулятора и веб-КП. Внутренние коммерческие предложения и документы в этот репозиторий не включены.
